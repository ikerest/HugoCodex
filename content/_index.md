Sitio web personal desarrollado para la práctica P1.2 de **Implantación de Aplicaciones Web (IAW)** en 2º de ASIR.

La web está generada de forma estática con **Hugo** y preparada para desplegarse mediante un servidor web **Nginx** en Linux. Al no depender de motores PHP ni bases de datos relacionales, el consumo de recursos en la máquina virtual es mínimo y la entrega del contenido es instantánea.
